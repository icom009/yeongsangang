# 한마디 글씨체

완성 사진의 한마디에 쓰는 글씨체입니다. 기본 글씨체만 저장소에 있고, 나머지는 `scripts/fetch_models.py`가
이미지를 만들 때 Google Fonts 저장소(github.com/google/fonts)에서 `font/extra/`로 받습니다(git에는 올리지 않음).

| 화면 이름 | 글씨체 | 만든 곳 | 라이선스 |
|---|---|---|---|
| 또박또박 (기본) | 온글잎 박다현체 (`OwnglyphPDH.ttf`) | VoyagerX(온글잎) · 박다현 | 온글잎 무료 글꼴 약관 (고치지 않고 그대로 씀) |
| 볼펜 | Nanum Pen Script | NHN(네이버) · 산돌커뮤니케이션 | SIL Open Font License 1.1 |
| 붓 | Nanum Brush Script | NHN(네이버) · 산돌커뮤니케이션 | SIL Open Font License 1.1 |
| 붓펜 | East Sea Dokdo (동해 독도) | 윤디자인 | SIL Open Font License 1.1 |
| 캘리 | Yeon Sung (연성) | The Yeon Sung Project Authors | SIL Open Font License 1.1 |
| 귀여운 | Gamja Flower (감자꽃) | 윤디자인 | SIL Open Font License 1.1 |
| 가느다란 | Hi Melody (하이멜로디) | 윤디자인 | SIL Open Font License 1.1 |
| 크레파스 | Gaegu Bold (개구) | 직지소프트 | SIL Open Font License 1.1 |
| 꾸밈 | Single Day (싱글데이) | DXKorea | SIL Open Font License 1.1 |

SIL OFL은 사진에 찍어 넣는 것, 웹 글꼴로 내보내는 것, 상업적 사용을 모두 허락합니다(글꼴 파일만 따로 팔 수는 없음).
고른 글씨체에 없는 글자(♥, ★, 드문 글자)는 기본 글씨체, 그다음 나눔고딕으로 채웁니다.
