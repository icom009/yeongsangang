# 노트북 부스 운영 안내

**구조:** 노트북 카메라로 찍고, 방문객은 QR을 찍어 **자기 휴대폰 데이터로** 사진을 받습니다.

| | 평소 모드 | 비상 모드 |
|---|---|---|
| 언제 | 늘 | 집 서버나 집 인터넷이 안 될 때 |
| 합성 | 집 GPU 서버 (`ysg26.cloud`) | 노트북 CPU |
| 노트북이 하는 일 | 크롬으로 화면·카메라만 | 부스 서버까지 직접 |
| 방문객이 받는 주소 | `https://ysg26.cloud/p/…` | `https://xxxx.trycloudflare.com/p/…` (임시 터널) |
| 합성 시간(한 장) | 약 0.7초 | 약 2~5초 (데스크톱 CPU 실측 1.8초, 노트북은 더 걸림) |
| AI 빛 보정 | 됨 | 안 됨 (GPU 없음) |
| 휴대폰 AI 효과(GPT) | 됨 | `.env.laptop`에 키를 넣으면 됨 |
| 노트북 인터넷 | 필요 | 필요 |

두 모드 모두 **노트북에 인터넷**(현장 와이파이나 휴대폰 핫스팟)이 있어야 방문객이 데이터로 받을 수 있습니다. 사진 한 장을 올리는 데 0.3~1MB쯤 듭니다.

## 미리 해 둘 일 (인터넷이 되는 곳에서)

1. **크롬**을 설치하고, `scripts\laptop\open-booth.bat`을 한 번 실행해 **카메라를 허용**해 둡니다. 부스 전용 크롬 프로필에 기억됩니다.
2. **Windows 설정**
   - 전원: 절전 '안 함', 화면 끄기 '안 함', 덮개를 닫아도 '아무 것도 안 함'
   - Windows 업데이트: 행사 기간 일시 중지
   - 알림: 방해 금지 켜기 (부스 화면 위에 알림이 뜨지 않게)
3. **비상 모드 준비** (집 서버만 쓸 거라면 건너뛰어도 되지만, 해 두기를 권합니다)
   - [Docker Desktop](https://www.docker.com/products/docker-desktop/)을 설치합니다 (WSL2 사용).
   - 저장소 받기: `git clone -b upgrade/v2 https://github.com/icom009/yeongsangang.git`
   - `copy .env.laptop.example .env.laptop` 후 **관리 비밀번호**(`YS_MANAGE_KEY`)를 채웁니다. GPT 효과를 쓰려면 `YS_OPENAI_KEY`도 채웁니다.
   - `scripts\laptop\start-fallback.bat`을 한 번 실행해 **서버 이미지를 만들어 둡니다**. 처음엔 몇 분 걸리고 인터넷이 필요합니다. 확인했으면 `stop-fallback.bat`으로 끕니다.
   - 노트북에서 빌드하기 어렵다면 집 PC에서 만든 이미지를 옮깁니다:
     집 PC에서 `docker save yeongsangang-booth:cpu -o booth-cpu.tar` → 노트북에서 `docker load -i booth-cpu.tar`

## 평소 모드

1. `scripts\laptop\open-booth.bat`을 더블클릭합니다. 크롬이 전체 화면으로 `https://ysg26.cloud`를 엽니다.
2. 끝낼 때는 **Alt+F4**.

합성·AI 빛 보정·GPT 효과는 모두 집 GPU 서버가 합니다. 노트북에는 아무것도 설치할 필요가 없습니다.

## 비상 모드

**언제:** 부스 화면이 안 열리거나, 찍을 때마다 "합성하지 못했어요"가 뜰 때 (집 서버나 집 인터넷 문제).
먼저 노트북 인터넷이 되는지(다른 사이트가 열리는지) 확인하세요. 노트북 인터넷 문제라면 비상 모드도 소용없고, 휴대폰 핫스팟으로 바꾸는 게 먼저입니다.

1. **Docker Desktop**을 켭니다.
2. `scripts\laptop\start-fallback.bat`을 더블클릭합니다.
   - 서버가 켜지고, 방문객 받기 주소(임시 터널)를 받으면 `받기 주소: https://….trycloudflare.com`이 나온 뒤 부스 화면이 전체 화면으로 열립니다.
   - QR에는 그 임시 주소가 저절로 들어갑니다.
3. 집 서버가 돌아오면: 마지막 방문객이 사진을 받아 간 뒤 `stop-fallback.bat` → `open-booth.bat`.

**주의**

- **임시 터널 주소는 켤 때마다 바뀝니다.** 비상 서버를 끄거나 노트북을 다시 켜면 이미 나간 QR 주소가 더는 열리지 않습니다. 비상 모드 중에는 끄지 마세요.
- 비상 모드 사진은 노트북의 `output-laptop` 폴더에 남고, 집 서버 관리 화면에는 보이지 않습니다. 관리 화면은 노트북에서 `http://localhost:8080/manage`로 엽니다.
- 터널로 들어오는 인터넷 요청에는 **방문객 받기 화면만** 열립니다. 촬영·관리 화면은 노트북 안에서만 열립니다.
- 임시 터널은 Cloudflare가 계정 없이 무료로 주는 것이라 가동을 보장하지 않습니다. 비상용으로만 씁니다.

## 인터넷이 아예 없을 때 (최후 수단)

방문객이 자기 데이터로 받으려면 노트북도 인터넷이 있어야 합니다. 노트북에 인터넷이 전혀 없으면, 노트북 핫스팟(또는 현장 공유기)에 방문객이 접속해서 받는 방식만 남습니다(README의 '플랜 B'). 이 경우 사진은 현장에서만 받을 수 있습니다.
